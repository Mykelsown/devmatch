## 4. CRITICAL RESEARCH — do NOT redo this (30+ min saved)

### R1. Browser Lace wallet (dapp-connector-api v4.0.1)

- Lace injects `InitialAPI` at `window.midnight.mnLace`.
- `InitialAPI.connect(networkId: string): Promise<ConnectedAPI>` — the modern API is **`connect(networkId)`**, there is NO `enable()`.
- `ConnectedAPI` (= `WalletConnectedAPI & HintUsage`) key methods:
  - `getShieldedBalances()`, `getUnshieldedBalances()`, `getDustBalance()`
  - `getShieldedAddresses()` → `{ shieldedAddress, shieldedCoinPublicKey, shieldedEncryptionPublicKey }` (bech32m strings)
  - `getUnshieldedAddress()` → `{ unshieldedAddress }`
  - `balanceUnsealedTransaction(tx: string, options?)` → `{ tx: string }` (serialized txs!)
  - `submitTransaction(tx: string): Promise<void>`
  - `getProvingProvider(keyMaterialProvider)` → in-wallet proving
  - `getConfiguration()` → `{ indexerUri, indexerWsUri, substrateNodeUri, networkId, proverServerUri? }` — use this to check network mismatch (we do, in `lace.ts`)
  - `getConnectionStatus()`, `hintUsage(methodNames)`
- Types live in `@midnight-ntwrk/dapp-connector-api` (installed). `window.midnight` is `{ [key: string]: InitialAPI }` via the package's global declaration.

### R2. midnight-js provider interfaces (v4.1.1) — IMPORTANT SHAPE CHANGE

```ts
interface WalletProvider {
  balanceTx(tx: UnboundTransaction, ttl?: Date): Promise<FinalizedTransaction>;
  getCoinPublicKey(): CoinPublicKey;          // SYNCHRONOUS, returns key object/hex
  getEncryptionPublicKey(): EncPublicKey;     // SYNCHRONOUS
}
interface MidnightProvider { submitTx(tx: FinalizedTransaction): Promise<TransactionId>; }
interface MidnightProviders {
  privateStateProvider; publicDataProvider; zkConfigProvider;
  proofProvider; walletProvider; midnightProvider; loggerProvider?;
}
```

Note: **submitTx is on `midnightProvider`, not on `walletProvider`.** A `walletProvider`
built from Lace must therefore pair with a `midnightProvider` that calls
`api.submitTransaction(...)`. See `lib/wallet-provider.ts` (now rewritten, see R9).

⚠️ The OLD draft returned a **Promise** from `getCoinPublicKey()` /
`getEncryptionPublicKey()` (via `api.getShieldedAddresses().then(...)`) but the
4.1.1 interface declares them **synchronous**. **FIXED**: `readWalletSnapshot(api)`
captures the keys once at connect time and `createWalletProviders(api, snapshot)`
returns them synchronously from the snapshot. Do not regress this.

### R6. How the caller ID works (sybil guard)

`callerId = persistentHash([pad(32, "devmatch:caller:"), localSecretKey])` — disclosed in the
ledger as the map key. For the frontend, `localSecretKey` **must be stable per wallet**, else
every `registerProfile` call mints a new identity. **Implemented** in `lib/contract.ts`:
`deriveLocalSecretKey(address)` = SHA-256 of `"devmatch:secret:" + address`, so caller ID is
stable across sessions. The witness returns `[context.privateState, secret]`. Keep it private,
never log it.

### R9. NEW this session (2026-08-06) — frontend wiring learnings

- **WASM imports need `vite-plugin-wasm`.** The Midnight onchain runtime ships ESM
  modules that `import` a `.wasm` file directly, which plain Vite cannot bundle.
  `vite-plugin-wasm` (^3.6.0) is the standard fix used by Midnight.js browser examples.
  Build target `es2022` emits top-level await natively, so no top-level-await transform
  plugin is needed (vite-plugin-top-level-await also pulls in @swc/core's native binary,
  which crashed this machine with SIGBUS — do not add it).
- **Wallet-provider bridge (final shape).** `createWalletProviders(api, snapshot)`:
  - `getCoinPublicKey()` / `getEncryptionPublicKey()` return `snapshot.coinPublicKey` /
    `snapshot.encryptionPublicKey` synchronously (captured at connect time).
  - `balanceTx(tx)`: `bytesToHex(tx.serialize())` → `api.balanceUnsealedTransaction(hex, { payFees: true })` →
    `Transaction.deserialize('signature', 'proof', 'binding', hexToBytes(balancedHex))`.
  - `submitTx(tx)`: `api.submitTransaction(bytesToHex(tx.serialize()))`, returns
    `tx.identifiers()[0] ?? tx.transactionHash()` as the tx id.
- **`useMidnight` flow**: `configureNetwork()` → `connectLace(NETWORK_ID)` → `readWalletSnapshot(api)`
  → `createProviders(api, snapshot)` → `deriveLocalSecretKey(address)` →
  `connectToDeployedContract(providers, secret)`. Contract call: `contract.callTx.registerProfile(commitment, Tier.Yellow, policy)`.
- **GitHub attestation (Level 3 prep)** is wired in `App.tsx`: button redirects to
  `${ATTESTER_URL}/auth/github`, the returned `attestedProfileHash` query param is stored
  in `localStorage` under `devmatch:attestedProfileHash`, then the URL is cleaned with
  `history.replaceState`. The attester service itself can stay a skeleton for Level 2.
